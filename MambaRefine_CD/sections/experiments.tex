\section{Experiments}
\label{sec:experiments}

\subsection{Datasets and Split Protocol}
\label{sec:datasets}
We evaluate \ours{} on two widely used binary CD benchmarks.

\textbf{DSIFN-CD}~\cite{shi2022dsamnet} contains 394 Gaofen-2 image pairs (1\,m GSD) covering six Chinese cities. We use the official image-level split (395 train, 48 val, 48 test), extract patches from training images only, and evaluate test images in patch mode with 25\% overlap. We refer to this as the \emph{clean split}.

\textbf{WHU-CD}~\cite{ji2019whu} is an aerial building CD dataset over Christchurch, New Zealand. We use the official three-way split and evaluate in the same patch mode.

\subsection{Implementation Details}
\label{sec:implementation}
Models are trained with AdamW (lr\,$=5\times10^{-5}$, weight decay\,$=0.01$), cosine scheduling with 2\,500 warmup steps, batch size 8, and $256\times256$ crops. Gradient norm is clipped at~0.5. Exponential moving average (EMA, decay\,$=0.999$) weights are used for inference. Augmentation: random horizontal and vertical flips. Training uses 16-bit AMP on a single NVIDIA Quadro GV100 (32\,GB). Ablation variants A0--A5 train for 30k iterations; the full model (A6) trains for 50k. The validation threshold is swept over $\{0.30,\ldots,0.60\}$ in 0.05 steps and fixed for test evaluation; test metrics are never used for selection.

\subsection{Evaluation Metrics}
\label{sec:metrics}
We report Precision (Pre), Recall (Rec), F1, IoU, and Overall Accuracy (OA) for the changed class via a global confusion matrix. F1 and IoU are primary metrics; OA is dominated by the unchanged class and is reported for completeness. We additionally evaluate Boundary F1 (BF1), Boundary IoU (BIoU), and Trimap F1 at 3-pixel tolerance to provide direct evidence of boundary localisation quality.

\subsection{Main Results}
\label{sec:main_results}
On the DSIFN-CD clean split, \ours{} achieves F1\,=\,95.67 and IoU\,=\,91.71 (averaged over two canonical runs) using 65.40\,M parameters. The best single run reaches F1\,=\,96.40 and IoU\,=\,93.04, indicating run-to-run variance is present. On WHU-CD, the model achieves F1\,=\,95.15 and IoU\,=\,90.76 at threshold 0.55.

\subsection{Ablation Study}
\label{sec:ablation}
Table~\ref{tab:ablation} presents a controlled ablation over seven variants on DSIFN-CD. The largest single gain comes from replacing the SimpleCNN-FPN baseline (A0) with MambaVision-S (A1), confirming the dominant role of the backbone. The A2 row (unsigned \drbi{} only) is a single verified run and should be interpreted cautiously; additional runs are left for future work. Adding signed temporal difference $F_2 - F_1$ (A3) increases F1 and IoU beyond A2, supporting the value of directional temporal evidence. ARF-FPN with CRAM-lite modulation (A4) provides a further small positive gain. Adding the boundary residual head alone without boundary-aware loss terms (A5) causes a regression ($-$0.77~F1), showing that the boundary head is not beneficial in isolation. The full model (A6) with CRAMLite, coarse auxiliary supervision, and boundary loss recovers and exceeds all prior variants, confirming that boundary refinement is most effective when trained jointly with the full loss.

\subsection{Boundary-Specific Evaluation and Backbone Scaling}
\label{sec:boundary_scaling}
We also evaluate boundary-specific metrics (BF1, BIoU, Trimap F1 at 3-pixel tolerance) across ablation variants on DSIFN-CD. The full model (A6) achieves BF1\,=\,71.94 and Trimap F1-3px\,=\,72.93, compared to BF1\,=\,61.36 for A1 and BF1\,=\,65.94 for A4, confirming that joint boundary supervision measurably improves boundary localisation. For reference, the WHU-CD full model achieves BF1\,=\,89.49, reflecting the simpler and more uniform building boundary structures.

Regarding backbone scaling on DSIFN-CD: moving from MambaVision-T (46.73\,M, F1\,=\,94.58, Pre\,=\,94.33, Rec\,=\,94.84) to MambaVision-S (65.40\,M, F1\,=\,95.67) yields a clear gain. Moving to MambaVision-B (113.37\,M, F1\,=\,95.77) adds only a marginal further gain at nearly double the parameter count, suggesting diminishing returns beyond MambaVision-S.

\subsection{Limitations}
\label{sec:limitations}
The Sobel-based boundary gate provides a useful spatial prior but is fixed, not learned end-to-end. DSIFN-CD evaluation protocols differ across studies, making strict cross-paper comparisons unreliable without a shared split. A proper same-protocol evaluation under the Mamba-CD-style patch split for DSIFN-CD is pending.
