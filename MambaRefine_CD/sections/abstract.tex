\begin{abstract}
Binary remote-sensing change detection requires spatially coherent change masks and precise boundary delineation. Existing CNN and Transformer-based Siamese architectures often fuse temporal evidence into a single shared representation, which can limit recovery of fine object boundaries. This paper presents \textbf{\ours}, a MambaVision-based binary change detection framework that explicitly decouples temporal evidence into complementary region-aware and boundary-aware responses. A shared MambaVision encoder extracts aligned multi-scale features from bi-temporal image pairs. The proposed \textbf{Differential Region--Boundary Interaction} (\drbi) module constructs a temporal descriptor from paired features, absolute difference, and signed difference, and routes it through separate gated region and boundary streams before multi-scale aggregation. An adaptive receptive-field FPN decoder aggregates the region features, and a bounded residual refinement head adjusts coarse predictions near boundaries using the finest boundary stream. Experiments on DSIFN-CD and WHU-CD show that the proposed model is competitive with recent Mamba-based change detection methods while providing explicit region--boundary temporal refinement. A controlled ablation over seven variants isolates the contribution of each component.
\end{abstract}
