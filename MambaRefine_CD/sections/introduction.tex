\section{Introduction}
\label{sec:introduction}

Remote-sensing change detection (CD) estimates a change mask from two images acquired over the same area at different times. The task is central to urban monitoring, disaster assessment, land-cover analysis, and infrastructure management. In practice, binary CD is difficult because the model must compare two observations while ignoring nuisance variation from illumination, seasonal changes, shadows, sensor differences, and small registration errors. These factors are most visible near object boundaries. A model can identify the approximate changed region and still produce poor masks if the predicted boundary is shifted, fragmented, or over-smoothed.

Deep CD methods have mostly followed two directions. Convolutional Siamese networks compare bi-temporal images through early fusion, feature concatenation, or feature differencing, as in FC-EF, FC-Siam-conc, and FC-Siam-diff \cite{daudt2018fully}. Later CNN-based encoder--decoder models improve localization through skip connections, dense feature reuse, attention, and multi-scale aggregation \cite{ronneberger2015unet,fang2022snunet,chen2021dasnet}. These models remain strong because convolutions provide useful locality and translation bias. However, their context modeling is constrained by the receptive field and by the design of the decoder. This can limit their ability to reason about spatially distributed changes in high-resolution remote-sensing scenes.

Transformer-based methods address long-range interaction more directly. BIT represents bi-temporal images using semantic tokens and applies a Transformer encoder to model spatial--temporal relations \cite{chen2022bit}. ChangeFormer uses a hierarchical Siamese Transformer and an MLP decoder for dense CD \cite{bandara2022changeformer}. These models show that global context is useful for distinguishing true changes from pseudo-changes. At the same time, attention-based models are costly for dense high-resolution prediction, and stronger global representation does not automatically resolve boundary errors. Change masks still depend on how temporal features are compared and how uncertain edge regions are decoded.

Recent visual state-space models (SSMs) provide another route for efficient global modeling. Mamba introduces selective state-space modeling for sequence processing \cite{gu2023mamba}, and VMamba adapts this idea to vision through two-dimensional selective scanning \cite{liu2024vmamba}. MambaVision further develops a hybrid Mamba--Transformer backbone for visual recognition and dense prediction \cite{hatamizadeh2025mambavision}. These backbones are attractive for remote-sensing CD because they provide multi-scale representation with a different efficiency profile from pure attention. Recent Mamba-based CD models have also started to explore state-space backbones for binary and semantic change detection \cite{chen2024changemamba}. However, using a Mamba-based encoder alone is not a complete solution. A CD model must still construct temporal evidence from the two images and preserve fine boundaries in the final mask.

Boundary modeling is therefore an important part of this problem. Prior segmentation work has shown that region-based objectives and standard decoder paths may under-emphasize contours, motivating boundary losses, shape streams, and coarse-to-fine refinement designs \cite{kervadec2019boundary,takikawa2019gated,qin2019basnet}. In remote sensing, boundary-aware learning has also been studied for dense prediction tasks where object delineation is important \cite{wang2021boundary}. A recent controlled benchmark of visual SSM backbones for remote-sensing segmentation further reported that boundary delineation remains a dominant failure mode under domain shift, suggesting that encoder scaling alone may be insufficient for boundary-sensitive dense prediction \cite{wasalathilaka2026controlled}. This observation is directly relevant to binary CD, where many errors arise at the transition between changed and unchanged regions.

Motivated by these issues, we propose \textbf{MambaRefine-CD}, a MambaVision-based architecture for binary remote-sensing change detection. The model uses a shared MambaVision encoder to extract aligned multi-scale features from the pre- and post-event images. It then builds temporal features using raw paired features, absolute difference, signed difference, and feature interaction. This gives the decoder access to both magnitude-based and direction-aware temporal evidence. The core module is \textbf{Differential Region-Boundary Interaction} (D-RBI), which applies separate learned responses to temporal difference features before decoding. D-RBI is intended to expose two complementary forms of evidence: stable region-level change cues and boundary-sensitive cues.

The full model combines D-RBI with an adaptive receptive field decoder and a bounded residual boundary refinement head. The adaptive decoder aggregates context at multiple spatial scales, while the residual head applies a controlled correction to coarse logits near boundaries. The residual correction is bounded so that refinement can adjust uncertain edge regions without freely replacing the global prediction. This keeps the architecture close to a standard binary CD pipeline while adding explicit temporal comparison and boundary-aware refinement.

The contributions of this paper are kept intentionally specific:
\begin{itemize}
    \item We present \textbf{MambaRefine-CD}, a MambaVision-based binary CD architecture that combines shared bi-temporal encoding, explicit temporal feature construction, and boundary-aware refinement.
    \item We introduce \textbf{D-RBI}, a region--boundary interaction module that produces separate learned responses from temporal difference features before decoding.
    \item We integrate signed temporal difference, adaptive receptive field decoding, and bounded residual boundary refinement into one CD pipeline and study their effect through controlled ablations.
\end{itemize}
