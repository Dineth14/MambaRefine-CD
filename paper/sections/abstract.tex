\begin{abstract}
Remote-sensing change detection requires spatially coherent masks and accurate object boundaries. Existing CNN and transformer-based methods model temporal differences effectively, but region-level change extent and boundary-level contour evidence are often fused into a single representation. This paper presents \ours, a MambaVision-based binary change detector that explicitly decouples low-frequency region cues from high-frequency boundary cues. The model combines Differential Region--Boundary Interaction, signed temporal difference, an adaptive receptive-field decoder, CRAM-lite attention, and boundary residual refinement. Using only verified metrics, \ours{} obtains 97.03 F1 and 94.23 IoU on DSIFN-CD, and 95.58 F1 and 91.53 IoU on WHU-CD. On LEVIR-CD validation, it obtains 92.29 F1, 85.69 IoU, and 99.27 OA. SECOND is discussed only as a future semantic change detection extension.
\end{abstract}
